# Smart-Shelf-Ana📦 SmartShelf Analytics

Inventory Optimization & Expiry Loss Reduction

A data-driven inventory analytics project designed to help retail businesses minimize product expiration losses and optimize stock management strategies using Python.

---

🚀 Project Overview

Retail businesses often suffer from financial losses due to inefficient inventory rotation and product expiration.

In this project, I analyzed a dataset of 1,000+ supermarket products to uncover inefficiencies and provide actionable insights that improve inventory decision-making.

The analysis focuses on:

- Calculating actual shelf life vs expected shelf life
- Comparing inventory strategies: FIFO vs FEFO
- Evaluating supplier performance based on loss contribution

---

🎯 Objectives

- Reduce financial losses caused by expired products
- Identify high-risk products and categories
- Improve stock rotation strategies
- Support data-driven procurement decisions

---

🛠️ Tools & Technologies

- Python – Core analysis and logic
- Pandas – Data cleaning, transformation, and aggregation
- Seaborn & Matplotlib – Data visualization
- Openpyxl – Exporting formatted Excel reports

---

📊 Key Insights

- 📉 Approximately 23% of total losses were caused by improper stock rotation
- 🥛 Perishable categories (e.g., dairy) showed the highest expiry rates
- 🔄 The FEFO strategy outperformed FIFO in reducing expiration losses
- 🏭 A small group of suppliers contributed to a disproportionate share of financial waste

---

🧠 What I Did

- Built a data analysis pipeline to clean and process raw inventory data
- Engineered features such as:
  - Shelf life duration
  - Expiry risk levels
  - Loss ratios per supplier

- Created visualizations to highlight:
  - Expiry trends
